# 汇总访客访问配置

用户已批准：第一版配置简洁，权限架构需可复用；施海莉不作为部门成员，能看授权视图与已发布成果、展开任务层级，但不能打开工作项详情。账号拼音加现有公司邮箱后缀，使用初始密码登录。

## 已有能力：复用而非重建

| 既有能力 | 来源 | 本轮处理 |
|---|---|---|
| 工作空间/项目成员、Admin/Member/Guest | db/models/workspace.py, project.py | 保留角色含义，新增独立访问配置 |
| 保存的项目视图与筛选、排序、时间窗口 | app/views/issue 与视图服务 | 沿用视图事实与同一筛选实现 |
| 任务树与父子关系 | db Issue.parent、sub_issue API | 汇总投影允许展开，详情拒绝 |
| 已发布成果/版本、材料预览 | app/services/artifacts | 沿用发布事实，授权与源任务详情独立 |
| 内网密码账号、自助修改密码 | authentication、Profile | 沿用，无 SMTP 依赖 |
| 既有管理员、部门成员操作 | 正常角色与项目成员 | 默认配置保持原行为 |

## 权限结构

- WorkspaceMember.access_profile：standard（默认）和 summary_observer（预设）。不增加特殊数字角色，不按用户/email/部门ID特判。
- 项目授权、视图授权使用规范化关联记录，空授权默认无范围；范围不能由查询参数扩大。
- 统一策略对象：按请求缓存身份/预设/授权范围，能力与范围分别校验。summary/read、detail/read、artifact/publication/read、artifact/material/read 分开。
- 共享认证后的入口执行默认拒绝；受限账号的工作空间接口须声明资源能力，新增未分类入口默认拒绝。网页和 API-key API 均执行。
- 汇总接口用固定字段白名单，不允许 fields/expand/description=true 扩权。客户端仅呈现后端有效能力。

## 能力矩阵

| 资源/动作 | 汇总访客 | 部门成员 |
|---|---|---|
| 授权视图定义与工作项汇总、父子层级 | 只读 | 原有行为 |
| 任务编号/标题/状态/负责人/日期/优先级/层级数量 | 只读 | 原有行为 |
| 任务详情/描述/评论/历史/版本/任务链接与附件 | 拒绝 | 原有行为 |
| 新建/编辑/拖动任务、保存共享视图/管理成员 | 拒绝 | 原有行为 |
| 已发布成果及明确发布的材料 | 范围内只读 | 原有行为 |
| 成果草稿/管理/发布/撤回 | 拒绝 | 原有行为 |
| 本人账号设置、修改密码、退出 | 允许 | 原有行为 |

成果中的源任务仅显示授权范围内汇总引用，不提供详情链接。发布材料可读不等于源任务全部附件可读。直接应用/外站自身仍执行其自身权限；本系统不能替另一个应用授权。

## 页面行为

沿用同一工作空间，汇总访客模式只呈现授权视图与成果。任务行/标题/卡片无详情链接，展开箭头独立、属性只读。未授权直接地址显示明确无权提示，不渲染正常详情或先显示后隐藏。权限加载失败也不回退正常成员界面。

第一批账号授权以数据库配置授予 AI战略部的项目和共享视图，排除示例/私人视图；不在代码写项目、用户、视图 ID。默认不自动继承未来新增项目或私人视图。若未来需增加范围，修改授权记录，不改代码。

## 验收及回滚

配对验证允许与拒绝：视图匹配、树展开、成果及已发布材料；直接任务地址、app/API-key详情、fields/expand/description 参数、评论/附件/导出/历史、越项目/越视图、草稿、写入。普通成员完整体验回归。受限账号凭密码真实登录、修改密码路径可用；初始密码无小时级过期限制。

在隔离数据库验证迁移/授权/数据投影和浏览器后上线；旧成员默认 standard。部署前数据库备份，保留镜像与 compose；任何拒绝边界无法证实则不发放账号。临时验收资源清理，保留已授权施海莉账号。

## 管理及维护

第一版复用保存视图的筛选与排序，访客以只读列表/树查看匹配项；不开放部门成员的看板拖动、筛选编辑或任务详情。树的数量与子项均基于同一视图匹配结果，筛选外子项不通过展开泄露。

范围要求有效工作空间及项目成员记录（Guest），再与独立项目/共享视图 grants 取交集。项目成员撤销、工作空间成员撤销、视图转为私人均立即收回范围。已签发附件预览链接也重新核验当前身份、权限和发布版本。

复用预设的运维命令（服务端管理员执行；不会重设密码或提升数字角色）：

```bash
python manage.py set_workspace_access_profile \
  --workspace <slug> --email <login> --profile summary_observer \
  --project <project-uuid> --view <shared-view-uuid> --dry-run
```

去掉 `--dry-run` 原子替换整组授权；重复 `--project`/`--view` 可授权多个资源。空范围默认拒绝。恢复 `standard` 仅恢复既有数字角色行为。访问配置字段对普通成员管理 API 为只读，首版不增加复杂权限编辑器。

受限账号不启动成员管理/搜索/通知/普通任务 stores；策略先于这些数据加载。全局任务活动/用户附件等未分类跨工作空间接口对受限身份默认拒绝；自助账号设置、工作空间选择等明确 bootstrap 接口例外。已有独立公开发布看板遵循其公开语义，本轮不更改公开分享合同；上线盘点时无有效公开看板。
