# 常用工作流导航检查与修复

范围：AI战略部成员与领导日常使用的项目/工作项、周月视图、父子关系、通知、附件；不改管理员设置或数据权限。

| 入口/路径                                   | 发现与处理                                                                                     |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 项目列表、项目视图、工作区视图 → 工作项侧栏 | 保持原路由及视图筛选；关闭侧栏不跳转页面                                                       |
| 工作项 → 子项 → 孙项 / 关联项 / 同级项      | 原先直接替换，无返回轨迹；增加当前侧栏会话的返回轨迹与“返回”按钮，返回祖先时收起轨迹，关闭清空 |
| 子项直接打开 / 全屏子项                     | 上级入口只有小标签；改为明确“返回上级”，全屏中前往上级完整页面，侧栏中保留侧栏                 |
| 关闭工作项                                  | 原先右箭头不易理解；改为 X 并增加可访问名称，与返回分开                                        |
| 工作项 → 附件预览 → 下载 / 新窗口           | 上一轮修复按钮；本轮让整个附件弹窗阻止底层外部点击，覆盖背景关闭场景                           |
| 附件预览 → Escape / 点击背景                | 阻止底层工作项响应同一次 Escape；只关闭顶层预览                                                |
| 通知页 → 返回 / 再次点击通知图标            | 已有独立返回入口和安全回退；复核保留来源路径、查询参数和锚点                                   |
| 移动端                                      | 保留原全屏工作项路径；使用明确上级入口，不强制桌面侧栏                                         |

返回轨迹仅存在于当前侧栏会话，按工作区隔离，最长30项；不借用浏览器后退，不跳出系统。原列表与筛选由现有页面保留。权限与父子关系编辑保持原有逻辑。

补充：同级项菜单从强制新窗口改为当前上下文内导航，并显示编号与名称。加载中与访问失败状态同样保留返回和关闭入口；失败提示中文化，不泄露受限工作项信息。

访问失败验收额外发现：错误状态原先属于整个侧栏，返回缓存中的正常工作项时仍显示失败。错误现在按工作项ID隔离，异步请求失败也不会污染另一工作项。
