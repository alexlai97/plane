# 成果与应用

工作区左侧「成果与应用」展示已发布的应用、演示和交付资料。每个工作区独立维护自己的成果与分类，入口为 `/<workspace-slug>/gallery/`，复用现有登录、成员、任务、对象存储和附件预览能力。

## 人的维护

部门成员通过「管理成果」「新建成果」填写名称、说明、类型和分类，关联已有工作项，选择任务材料、上传文件或添加应用与演示链接，并选择封面及主要按钮。内容应来自可核对的实际工作；任务完成不等于应用上线，不填写未经记录的业务效果。

「保存草稿」只保存待编辑内容。「预览草稿」检查效果。「发布」才更新展厅。新草稿仅创建者和工作区管理员可维护；首次发布后成为部门共享成果，成员可以协作维护，撤下后仍可继续维护。来源项目权限仍须满足，工作区管理员不能绕过私有项目成员限制。

成果详情有稳定地址，可查看交付材料、预览附件和返回关联工作项。修订历史可恢复成草稿，再发布才替换展厅内容。撤下会隐藏展厅卡片；删除成果不会删除来源任务或共有的原始附件。旧版本保存内容与选中材料的引用，不保存外部网站或文件字节的历史副本。

分类可新增和改名；改名立即影响使用该分类的展示。正在被成果或历史修订使用的分类不可删除。并发编辑通过版本号检查；遇到冲突保留本地输入，重新加载并合并后再保存。

## 数据与接口

运行数据使用数据库中的 Artifact、Category、Source、Material 和 Revision，不读取静态内容清单，不因内容变更重建镜像。会话接口为 `/api/workspaces/<slug>/artifacts/`，API Key 接口为 `/api/v1/workspaces/<slug>/artifacts/`；UI 与 API 使用同一业务服务和权限规则。写既有记录必须提供 `version`；缺少返回 400，过期返回 409。PATCH 未提供的字段保持原值，显式空数组或 null 才清空。

原清单保留在 `apps/api/plane/app/data/archive/gallery.json`，仅作为显式迁移输入：

```sh
python manage.py import_artifacts --workspace <slug-or-UUID> --owner <active-email-or-UUID>
# 核对 dry-run 后才执行 --apply。
```

导入按工作区和历史卡片 key 生成稳定 ID，全部验证后事务提交。相同输入重复执行跳过；遇到已经被人工修改的同 ID 记录拒绝覆盖。生产迁移前保留 pg_dump 和 Compose 配置备份。首次从历史清单迁移时，先执行数据库迁移，再导入历史内容，最后切换前后端镜像。后续版本升级只执行新增迁移，不重复导入清单，以免与人工维护的数据冲突。

## 文件与预览

沿用附件上传大小配置和共享预览服务。Office 文件超过 30 MiB 提供下载；格式支持与大小限制由同一服务规则决定，界面和预览接口一致。上传材料归属于成果；原任务材料仍归属于原任务。预览每次检查有效材料、所选引用、成员和来源项目权限，转换服务只能使用短期签名的服务端指定来源。

`ATTACHMENT_PREVIEW_SOURCE_URL` 指定转换服务能够访问的内部 API 来源，默认 Docker 服务地址 `http://api:8000`；隔离验收环境必须指向隔离 API，不能使用生产数据库读取草稿。派生封面通过数据库引用授权；不是另一个业务数据源。失效的来源或材料会被标明，需修复后再发布。

## 验证与构建

后端契约测试在 `plane.tests.unit.test_artifacts`，替代旧的静态 gallery 配置测试；使用隔离测试数据库执行，不得指向生产数据库。同步回归现有附件预览、任务模板和筛选排序。前端保留 `bokang/tests/gallery-ui.test.mjs` 并新增成果表单 helper 测试；完整生命周期必须在实际浏览器操作，查看截图及部署后的运行结果。

前端使用 `bokang/Dockerfile.runtime`；后端使用 `bokang/Dockerfile.artifact-api`，通过 `BASE_IMAGE` 指定已验证、含现有依赖的后端基线镜像。固定提交标签并保留上一版镜像。没有新增代码执行、网页生成或外部模型能力。


## 展示体验与工作区外观

展厅提供卡片和列表两种布局，共用相同成果与权限。名称与封面可打开详情；材料数量入口定位到交付材料。搜索、分类、排序和分组通过 URL 保留，可分享当前视图；布局偏好按工作区保存在浏览器，明确 URL 布局优先。返回展厅会恢复筛选与滚动位置。文件行显示大小与默认主材料，直接复用已有附件预览和下载。封面图片放大使用对应附件的授权来源；PDF 派生缩略图打开原 PDF 材料。

HTTP 内网中浏览器可能禁止自动剪贴板。复制按钮提供选中链接的手动复制对话框，只有真正复制成功才显示成功提示。撤下、删除和恢复采用统一确认对话框，失败保留对话框及输入。所有材料链接在保存和发布前校验为有效 HTTP(S) 地址，列表与详情再次过滤不安全地址。

工作区外观存储于 `Workspace.appearance`，由现有管理员工作区更新接口配置；无工作区 UUID 主题分支。支持 `theme: "blue-gray"` 和 `organization_logo_url`；嵌套 PATCH 保留未提交键，显式 null 清除。工作区 `logo_url` 是部门标识，侧栏组织标识独立配置。未经配置的工作区使用系统默认外观，现有深色和用户自定义主题优先。
