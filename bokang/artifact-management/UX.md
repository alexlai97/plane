# 人的维护路径

现有展厅面向领导，保持卡片/分类/主操作。右上角加「管理成果」「新建成果」，只对可创建成员显示。成果详情有明确「返回成果与应用」，所有者/admin 可点「编辑」。详情必须有稳定 URL，可复制链接。

管理页是当前用户能维护/查看管理信息的列表，显示标题、分类、状态（草稿/已发布/已撤下）、未发布修改提示、更新时间。搜索后仍保留新建入口。空列表给「新建成果」。

创建和编辑使用同一个表单组件，页面而非复杂嵌套弹窗：名称、说明、类型（短文本）、分类；「关联工作项」搜索选择；已选任务的材料可以添加到成果；链接列表可加/删（标题、地址、用途）；文件上传直接复用后端成果附件接口。新建时首次「保存草稿」创建对象并进入编辑地址，然后上传按钮可用，说明准确且简短。既有任务材料和链接可在首次保存前选择。封面只可选已选图片；主操作可选详情、选中材料、选中链接。

底部「保存草稿」「预览草稿」「发布」分开。未保存修改先保存后预览/发布，版本冲突保留本地编辑，提示重新加载后合并。撤下/删除在编辑页更多操作；确认文字包含具体成果名。已发布成果保存不会立即改领导页面；保存成功提示可继续发布。发布结果可一键查看。

修订面板显示版本、时间、修改者，详情和「恢复为草稿」。恢复后明确需再发布，不直接替换发布版。

分类管理在管理页的「分类管理」面板中：列表改名、增加、删除；被使用类别不允许删除，展示 usage_count 和原因。中文按钮、错误、状态；不把 API/资源实体类型等实现字段显示给产品用户。

不用新增主题、模板系统或代码执行环境。表单使用现有 UI 组件、整齐间距和适量 table，窄屏自然换行。已有附件预览 modal 只复用一次；来源任务继续通过已有工作项入口。
